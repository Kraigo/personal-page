# kraigo.dev
#
# This page is meant to be reached by a link I hand out — not found in search,
# not archived, not scraped into a training set.
#
# Note the deliberate asymmetry below:
#
#   * Search engines are ALLOWED to fetch the page. That is not an oversight.
#     Removal from an index is driven by the "noindex" meta tag in index.html,
#     and a crawler can only obey a tag it is permitted to read. Blocking
#     Googlebot here would leave it unable to see "noindex" while still free to
#     list a bare URL it discovered via a link elsewhere — the opposite of the
#     intent. Letting it in is what gets the page dropped.
#
#   * Everyone else is blocked outright.
#
# robots.txt is a request, not a control. It is honoured only by crawlers that
# choose to honour it.


# ── Search engines: allowed in, so they can read "noindex" and drop the page ──
